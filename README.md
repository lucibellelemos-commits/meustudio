# LCI Studio

Backup dos arquivos do site do LCI Studio. O site em si é editado e publicado no Framer (projeto **STUDIO LIO NEW**). Este repositório guarda as peças que saem dele.

| Pasta | O que tem |
|---|---|
| `logo/` | Logo "LCI Studio®" numa linha em preto e em branco (PNG), o HTML que gera a logo e a fonte Inter Tight 500 |
| `cms/` | `lio_projetos.csv`, com os 10 projetos (título, slug, categoria, ano, texto, imagens, legendas e proporções), e o script que gera o CSV |
| `framer/code/` | Componentes de código usados no Framer: slideshow da home e override da logo |
| `mockups/` | Prints do site em mockup de desktop |
| `textos/` | Textos institucionais, SEO e contatos |

As imagens dos projetos ficam hospedadas no Framer (`framerusercontent.com`). Os links estão no CSV.
